# MCP widget

The interactive Excalidraw MCP App is served from the checked-in `apps/server/src/mcp/vendor/mcp-app.html`. It is a prebuilt HTML widget, not generated by Excalistack's normal build. The MCP server reads it when registering the `ui://excalidraw/mcp-app.html` resource.

## Why it is vendored

Keeping the widget in the repository makes production startup independent of upstream availability and avoids fetching executable UI code at runtime. The vendored Excalidraw MCP server code registers the widget and its tools; Excalistack adds its own persistent library tools alongside them.

The widget currently imports React, Excalidraw, and `morphdom` from `esm.sh`. The official tool registration declares `https://esm.sh` as a resource and connection domain for MCP Apps hosts. Thus the HTML is served locally, but the widget's browser still needs access to that CDN for these modules.

## Provenance

The widget is extracted from `dist/mcp-app.html` inside a release `.mcpb` asset from [`excalidraw/excalidraw-mcp`](https://github.com/excalidraw/excalidraw-mcp), an MIT-licensed project. The selected release and exact bundle and extracted-widget SHA-256 values are recorded in [`mcp-app-provenance.json`](../apps/server/src/mcp/vendor/mcp-app-provenance.json); treat that generated record as the source of truth rather than copying version numbers into this guide.

## Update the widget

Run from the repository root (or any directory):

```shell
scripts/update-mcp-widget.sh
```

The script downloads the pinned release asset, verifies its SHA-256 before extracting the HTML, then updates the vendored file and provenance record. It requires `curl`, `unzip`, and either `sha256sum` or `shasum`.

To adopt a newer upstream release:

1. Review the upstream release and confirm the MCPB contains `dist/mcp-app.html`.
2. Obtain the asset's SHA-256 from the upstream release metadata and independently verify it.
3. Update the pinned version and checksum together in `scripts/update-mcp-widget.sh`.
4. Run the script and review the widget and provenance diffs.
5. Run the server tests and manually verify `create_view`, fullscreen editing, checkpoint restore, and `save_to_excalistack` in a supported MCP client.

Do not fetch or execute the widget from an unpinned URL at runtime. The MCPB is an upstream desktop-install bundle, not Excalistack's runtime package; this project extracts only its built widget.
